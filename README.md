# Page Patterns for Claude Code

Pattern backgrounds for website sections, designed by Claude. This plugin adds the Page Patterns MCP server and a skill that teaches Claude the workflow: read your page, explore variants, show you options in your real page and add the one you pick.

## Install

You need Node 22 or later and a free key from [pagepatterns.com/account](https://pagepatterns.com/account) (sign in with GitHub or Google).

```
/plugin marketplace add OldMillennial/page-patterns-claude
/plugin install page-patterns@page-patterns
```

Claude Code asks for your key and keeps it in its secure store. To change it later, run `/plugin`, pick page-patterns and choose Configure options.

Then ask, for example: "Make the hero background on my home page more interesting."
